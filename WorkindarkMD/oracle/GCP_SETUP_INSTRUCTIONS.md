### **Инструкция по настройке Google Cloud для проекта "Трио"**

**Цель:** Создать "дом" для нашего проекта, настроить базу данных и получить ключи доступа, которые я буду использовать для разработки.

---

#### **Шаг 1: Создание нового проекта Google Cloud**

Каждый проект в Google Cloud — это изолированное пространство со своими ресурсами.

1.  Откройте консоль Google Cloud: [console.cloud.google.com](https://console.cloud.google.com).
2.  Вверху страницы, рядом с логотипом Google Cloud, кликните на выпадающее меню выбора проекта.
3.  В открывшемся окне нажмите **"СОЗДАТЬ ПРОЕКТ"** (NEW PROJECT).
4.  Дайте проекту имя, например, `Trio-Ecosystem`.
5.  Google Cloud создаст для проекта уникальный ID (например, `trio-ecosystem-123456`). Он нам понадобится позже.
6.  Нажмите **"СОЗДАТЬ"**.

---

#### **Шаг 2: Активация необходимых API**

Нам нужно "включить" сервисы, которые мы будем использовать.

1.  Убедитесь, что выбран ваш новый проект (`Trio-Ecosystem`).
2.  Перейдите в раздел **"API и сервисы"** -> **"Библиотека"**.
3.  Найдите и активируйте (нажмите **"ВКЛЮЧИТЬ"** / **"ENABLE"**) следующие три API по очереди:
    *   `Cloud Firestore API` (наша база данных)
    *   `Cloud Functions API` (наш "мозг" Gem.Bot)
    *   `Cloud Build API` (необходимо для развертывания функций)

---

#### **Шаг 3: Создание базы данных Firestore**

1.  В меню навигации (слева) выберите **Firestore**.
2.  Нажмите **"СОЗДАТЬ БАЗУ ДАННЫХ"** (CREATE DATABASE).
3.  Выберите **"Собственный режим"** (Native mode).
4.  Выберите регион, который находится ближе к вам (например, `europe-west3` для Франкфурта). Это уменьшит задержки.
5.  Нажмите **"СОЗДАТЬ"**.

---

#### **Шаг 4: Создание Service Account (Ключ для меня)**

Это специальный "пользователь" для программ, который позволит моему коду (Cloud Functions) взаимодействовать с вашей базой данных.

1.  Перейдите в **"IAM и администрирование"** -> **"Сервисные аккаунты"**.
2.  Нажмите **"+ СОЗДАТЬ СЕРВИСНЫЙ АККАУНТ"**.
3.  Назовите его `gem-bot-worker`.
4.  Нажмите **"СОЗДАТЬ И ПРОДОЛЖИТЬ"**.
5.  На шаге "Предоставьте этому сервисному аккаунту доступ к проекту" добавьте две роли:
    *   `Cloud Datastore User` (позволит читать и писать в Firestore)
    *   `Cloud Functions Invoker` (позволит вызывать функции, если понадобится)
6.  Нажмите **"ПРОДОЛЖИТЬ"**, а затем **"ГОТОВО"**.
7.  Теперь найдите созданный аккаунт (`gem-bot-worker`) в списке, нажмите на три точки в конце строки и выберите **"Управление ключами"**.
8.  Нажмите **"ДОБАВИТЬ КЛЮЧ"** -> **"Создать новый ключ"**.
9.  Выберите тип **JSON** и нажмите **"СОЗДАТЬ"**.
10. **Ваш браузер скачает JSON-файл. Это самый важный файл. Сохраните его в надежном месте. Его содержимое понадобится мне на следующем шаге.**

---

#### **Шаг 5: Создание трех API-ключей (Ключи для внешних сервисов)**

Эти ключи — как пароли для доступа к нашему API-шлюзу.

1.  Перейдите в **"API и сервисы"** -> **"Учетные данные"**.
2.  Нажмите **"+ СОЗДАТЬ УЧЕТНЫЕ ДАННЫЕ"** -> **"Ключ API"**.
3.  Google создаст ключ. Скопируйте его. Нажмите на карандаш (редактировать), чтобы дать ему имя, например, `cbot-oracle-key`. Сохраните.
4.  **Повторите этот процесс еще два раза**, чтобы у вас было три уникальных ключа. Назовите их осмысленно:
    *   `cbot-oracle-key` (для нашего cBot)
    *   `strategist-panel-key` (для панели управления)
    *   `internal-services-key` (для будущих нужд)

---

**Пожалуйста, выполните эти шаги. Как только вы будете готовы, просто дайте мне знать, и мы перейдем к следующему этапу, где вы безопасно передадите мне необходимые данные.**
